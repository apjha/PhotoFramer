How printing works
  1. Print… opens your device's print dialog — pick your printer there (or “Save as PDF”).
  2. Set paper size to .
  3. Set scale to 100% / Actual size (not “Fit to page”) and margins to None, so prints come out at the exact frame size.

Browsers don't let web pages pick a printer directly — this is the same on every OS, so the choice is always in the print dialog.
